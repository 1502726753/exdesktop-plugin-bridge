# Пробная Windows-сборка

Ветка предназначена для проверки подготовки зависимостей и компиляции exDesktop на GitHub Actions; это не готовый клиент для установки. Исходники фиксированы на commit `a4363ff23433ea05ab608a8eeced2e08e0aa8203`, к ним применяется экспериментальный патч событий.

Пробная сборка использует публичные тестовые Telegram API credentials из документации исходного проекта и не предназначена для входа в аккаунт или распространения. Запуск на Windows расходует минуты GitHub Actions; эксперимент ограничен двумя часами. Артефакт не публикуется.

До выпуска отдельно нужно реализовать и проверить изоляцию данных, отключение обоих штатных механизмов обновления и корректный запуск рядом с обычной версией. Текущий патч не сохраняет удалённые сообщения и не гарантирует доставку каждого события.
