# exDesktop Plugin Bridge

Экспериментальная основа для расширения API плагинов exDesktop. Готовой сборки Windows пока нет.

## Текущее состояние

- Базовая версия: exDesktop `v7.3.3.11`, commit `a4363ff23433ea05ab608a8eeced2e08e0aa8203`.
- Патч `patches/deleted-message-event.patch` — прототип события `updateDeletedMessage` для сообщений, уже находящихся в памяти клиента. Событие отправляется перед обработкой удаления и содержит данные через существующий `MessageToJson`.
- Патч не гарантирует сохранение сообщений: событие может пропускаться при повторном входе, не охватывает отсутствующие в памяти сообщения, использует существующее ограничение `account=0`; медиаконтент и архив не реализованы.
- Патч проверен на применимость к указанной версии, но не скомпилирован и не проверен в работающем клиенте. Не использовать как гарантию приватности или сохранности данных.

## Применение патча

В клоне исходников exDesktop, переключённом на указанный commit:

```sh
git apply --check /path/to/deleted-message-event.patch
git apply /path/to/deleted-message-event.patch
```
